# Diário de sessões de desenvolvimento

Cada arquivo aqui resume uma sessão de trabalho com o Claude Code: o que foi feito,
**por que** (causa raiz, não só o sintoma), os commits envolvidos e o que ficou
pendente de validar em bancada.

Existe porque o desenvolvimento acontece em uma máquina e o teste/deploy em outra
(a VM do cliente), e o Claude Code roda nas duas — as conversas cruas não viajam
pelo git, então este diário é o contexto compartilhado entre as duas pontas.

Convenção: `AAAA-MM-DD-<tema>.md`, mais recente é a fonte da verdade sobre o estado
atual. Ao retomar trabalho em qualquer máquina, leia o mais recente antes de mexer.
